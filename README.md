# <div align='center'>Automata-Compiler</div>
A mini compiler + visual playground for building and analyzing programs and network protocol state machines using automata theory.

This project combines core compiler design with formal verification concepts and includes:

- A custom mini programming language (variables, arithmetic, print)
- Lexer, parser, and AST-based interpreter
- A DFA (finite automata) engine for modeling state machines
- A protocol validator to verify packet sequences against defined rules
- A simulation environment to detect invalid transitions and logical errors
- A visual interface to track execution and state changes

The system demonstrates how formal languages and automata theory can be applied to both program execution and real-world problems like network protocol validation and security analysis.
